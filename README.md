# Лайм — умный маркетинг ВКонтакте

Интерактивный русскоязычный прототип панели для продвижения сообщества VK с командой маркетинговых агентов. Запускается как статическая страница: серверная сборка и зависимости не нужны.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

## Что уже работает

- Панель показателей, график охвата и источники переходов.
- Интерфейс команды из четырёх ролей: Стратег, Креатор, Таргетолог и Аналитик.
- Форма создания кампании с проверкой полей; черновики хранятся локально в браузере.
- Выгрузка демонстрационного отчёта в CSV, переключение периода и уведомления.
- Адаптивная компоновка для мобильных экранов.

## Важно: демо, а не подключённый бот

Показатели и отметка «ВКонтакте подключён» — демонстрационные. Приложение сейчас не обращается к API VK, не публикует посты и не запускает рекламу. Для реальной интеграции понадобится серверная часть, приложение VK и безопасное хранение ключей доступа (никогда не хранить токены в браузере).

Рекомендуемый контур агентов: **Стратег** формирует гипотезу и сегмент → **Креатор** готовит варианты контента → **Таргетолог** предлагает аудиторию и бюджет → **Аналитик** сравнивает результаты и предлагает корректировки. Перед публикацией или расходованием рекламного бюджета необходима явная проверка и одобрение владельцем сообщества. Настраивайте частотные лимиты, рекламируйте только релевантные предложения в разрешённых местах и не используйте автоматические массовые личные сообщения или обход ограничений платформы.
